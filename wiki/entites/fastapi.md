# FastAPI

Framework web Python asynchrone, basé sur Starlette et Pydantic, orienté
construction d'APIs HTTP rapides avec validation de schémas intégrée.
Souvent utilisé pour exposer des services LLM/IA : gestion native de
l'async (utile pour les appels longs aux modèles) et génération
automatique d'OpenAPI.

## Usages observés dans le wiki

- Couche métier d'un système d'inventaire automobile piloté par LLM —
  gestion des API, des sessions et orchestration de l'agent — voir
  [[2026-05-18-agentic-ai-fleet-management]].
